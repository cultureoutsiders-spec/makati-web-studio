# Prospects — batch 8

Five more Makati businesses with **no website of their own**, researched 2026-09-11. Same offer:
**PHP 25,000 one-time, no retainer (first 5 paying clients), then PHP 35,000.** Client owns the
code; price includes going live on their domain.

Batch 8 theme: **studios & creative / leisure spaces** — places you book time in.

**STATUS: researched, not built.** Sites not started.

## How the check was done

Same as batch 7: Googled by name, then likely domains requested with `curl` to tell a real own
site from a parked "lander" or a lapsed one. A lead qualifies only if every result is a Facebook
page, an Instagram account, a directory listing, or a booking-widget page (SimplyBook,
Booking.page, ClassPass, about.me, Linktree — none of which counts as an own website), with no
working own domain.

**Disqualified on checking this round (they have their own live site) —** The Bouldering Hive
(`bhiveph.com`), 8Studio reformer Pilates (`8studio.ph`, has one), Sunspace Salcedo
(`sunspace.ph`), Coal Tattoo (`coaltattoostudio.com`), Inkwell Tattoo (`inkwelltattoomanila.com`),
Options Studio Pilates (`optionsstudioph.com`), Bumi and Ashe (`bumiandashe.com` — already
disqualified in batch 5).

## The five

### 1. Arté Tattoo & Piercing Studio — tattoo + piercing
- **Where:** Barangay Poblacion, Makati (confirm exact address off IG).
- **Presence:** Instagram (`@artetattooph`, ~35K followers) + Facebook. **No website**, no own
  domain found. Open daily, hours vary.
- **Contact:** Instagram / Facebook DM. Grab a number off the profile.
- **Pitch angle:** a busy Poblacion studio whose artists, styles, healed-work galleries, pricing
  bands, aftercare and walk-in vs. appointment rules all live in Stories and highlights. A site
  with an artist roster (each with a portfolio and a style tag), a deposit-and-book flow, an
  aftercare page, and a piercing price list is the obvious upgrade, and lets them show healed
  work properly instead of in a grid.
- **Template:** artist roster + portfolio grid + booking/deposit form + aftercare page. Adapts the
  Gray Matter "archive index" object-label grid to tattoo portfolios, plus the COREX booking flow.

### 2. Ymahe Tattoo Studio — fine-line tattoo
- **Where:** Ground floor, Coro Hotel, Barangay Poblacion, Makati.
- **Presence:** Instagram only. **No website**, no own domain found. Free consultation, books via
  DM.
- **Contact:** Instagram DM.
- **Pitch angle:** a fine-line specialist inside a boutique hotel — the aesthetic is precise and
  quiet, and a grid of IG posts flattens it. A restrained portfolio site with a consultation form
  (reference images, placement, size, budget), a healing/aftercare page, and the hotel-lobby
  location done properly sells the specialism. Distinct from Arté: one style, one artist, calmer.
- **Template:** lean portfolio + consultation form. The Hoshi House "slow vertical" restraint
  applied to a tattoo studio.

### 3. sóma reformer — boutique reformer Pilates studio
- **Where:** Salcedo Village, Makati (confirm address off IG).
- **Presence:** Instagram (`@somareformer`). `somareformer.com` redirects to an unrelated **UK**
  studio; the PH studio has **no site** of its own. Listed on ClassPass.
- **Contact:** Instagram DM. **Verify it is a distinct, currently operating Makati studio before
  pitching** — several similarly named Pilates studios exist in the area (8Studio, Options,
  Sunspace, "pilates.by.a").
- **Pitch angle:** reformer Pilates sells on the timetable, the instructor bios, the intro-offer,
  class sizes, and package pricing. A ClassPass tile and an IG grid do none of that well. A site
  with a live-looking weekly schedule, instructor pages, a first-timer offer, and a package/booking
  form is a straight upgrade.
- **Template:** schedule grid + instructors + pricing tiers + intro-class form (the COREX / KSK
  pattern in a calm, pale boutique-fitness register).

### 4. Fez Spa — massage & spa (with sauna)
- **Where:** 5030 P. Burgos Street, Barangay Poblacion, Makati.
- **Presence:** Facebook + directory listings (2026 Yelp / Tripadvisor spa lists). `fezspa.com`
  resolves but is a parked **"lander"**, **not a real site.** **No working website.**
- **Contact:** Facebook Messenger / walk-in. Grab a number off the About tab.
- **Pitch angle:** a P. Burgos spa competes on menu clarity and feeling clean and legit before you
  walk in. Right now the service menu, prices, room types, the sauna, and hours are scattered
  across posts and third-party listings. A site with a proper treatment menu, durations and
  prices, a gallery that looks the part, and a booking form does the pre-selling.
- **Template:** treatment menu + duration/price tables + gallery + booking form. The MOOI
  "treatment index" pattern, warmer and more sensory.

### 5. Ludo: Boardgame Store — board-game shop + play space
- **Where:** Makati (confirm address off FB).
- **Presence:** Facebook (`/Ludogamescafe`). `ludoboardgame.com` resolves but is a parked
  **"lander"**, **not a real site.** **No working website.**
- **Contact:** Facebook Messenger.
- **Pitch angle:** two businesses in one room — retail (what's in stock, pre-orders, new
  releases) and a play space (table rates, house library, events, game nights). Neither reads on

- **Template:** stock list + table-booking form + events calendar. Reuses the Spindle Hole "crate"

  tattoo studios and sóma, Facebook for Fez and Ludo). Grab an email off each profile first if
  there is one.
- **Build order that reuses work:** Gray Matter grid + COREX booking → Arté Tattoo; Hoshi House
  restraint → Ymahe; COREX / KSK schedule → sóma reformer; MOOI "treatment index" → Fez Spa;
  Spindle Hole "crate" + All Stars board → Ludo.
- **Re-verify before pitching** (the One World Butchers lesson): sóma reformer most needs a
  distinct-and-operating check; the rest need a "still no live site" check at send time.
