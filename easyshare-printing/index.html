The bit that saves you a trip

Send the file. We'll preflight it.

Most reprints go wrong because of the file, not the print — wrong colour space, no bleed, fonts not embedded, images at 72dpi. We check yours before we run it and flag anything that'll cause a problem, so you're not paying to print a mistake.
